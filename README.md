# Quests

بوت Discord احترافي للحفاظ على تفاعل المجتمع عبر **Daily Quests** و**Weekly Quests** و**Seasonal Quests**، مع XP، مستويات، Quest Streak، Achievements، Mystery Boxes وفعاليات تفاعلية بالأزرار.

## الأنظمة

### 📋 Daily Quests
مهام تتجدد يومياً، ويكون التقدم مستقلاً لكل عضو. الأنواع الحالية تشمل الرسائل، التفاعلات، الوقت في القنوات الصوتية، المشاركة في الفعاليات، استخدام الأوامر والتفاعل في قنوات مختلفة.

إكمال جميع مهام اليوم يمنح العضو **Mystery Box** واحداً.

### 📅 Weekly Quests
مجموعة مهام أسبوعية بأهداف أكبر ومكافآت أعلى. التقدم يستمر طوال الأسبوع ولا يتأثر بتجدد المهام اليومية.

### 🌟 Seasonal Quests
كل موسم له فترة بداية ونهاية، ويمكن للإدارة إعداد الموسم بالكامل من داخل Discord.

### ✨ XP & Levels
كل نقاط المهام تتحول إلى XP، ويمكن للإدارة تحديد XP لكل مستوى وربط رتب Discord بمستويات معينة.

### 🔥 Quest Streak
يتم احتساب السلسلة اليومية عند إكمال مهام يومية، مع حفظ أفضل سلسلة وصل إليها العضو.

### 🏅 Achievements
إنجازات تلقائية للتقدم، النقاط، الـStreak، الصناديق والمستويات وإكمال يوم كامل.

### 🎁 Mystery Box
الصندوق يُكتسب بعد إكمال جميع مهام اليوم. عند فتحه يختار البوت رتبة من الرتب المضافة من داخل Discord، مع وزن لكل رتبة للتحكم في ندرتها.

بعد منح الرتبة، يرسل البوت للعضو رسالة في الخاص تطلب منه فتح تذكرة لاستلام المكافأة.

### 🎉 Events
الإدارة تنشئ فعالية من `/quest-event create`، ويظهر Panel يحتوي أزرار:

- ✅ أشارك
- 👥 المشاركون
- ⏹️ إنهاء الفعالية

عند الضغط على المشاركة، يتم تسجيل العضو مرة واحدة فقط، ومنحه نقاط الفعالية، وتسجيل المشاركة ضمن مهام الفعاليات اليومية/الأسبوعية/الموسمية.

## الأوامر العامة

`/help` — عرض جميع الأنظمة والأوامر.

`/quests` — عرض المهام اليومية والتقدم والمكافآت.

`/quests-weekly` — عرض المهام الأسبوعية.

`/quests-season` — عرض مهام الموسم ونقاط الموسم.

`/quests-top` — ترتيب عام أو أسبوعي أو موسمي.

`/quest-profile` — عرض المستوى وXP والنقاط والـStreak والصناديق والإنجازات.

`/quest-streak` — عرض السلسلة الحالية وأفضل سلسلة.

`/achievements` — عرض الإنجازات المفتوحة والمقفلة.

`/mystery-box` — فتح صندوق حصلت عليه.

`/quest-event create` — إنشاء فعالية تفاعلية.

`/quest-event end` — إنهاء الفعالية الحالية.

`/quest-event info` — عرض معلومات الفعالية الحالية.

## 🛠️ إدارة كاملة من Discord

كل إعدادات Quests القابلة للتغيير أصبحت متاحة للإدارة من داخل Discord عبر:

`/quests-admin`

ويشمل:

- `/quests-admin view` — عرض إعدادات النظام.
- `/quests-admin mystery-role-add` — إضافة رتبة إلى Mystery Box مع وزن مخصص.
- `/quests-admin mystery-role-remove` — إزالة رتبة من Mystery Box.
- `/quests-admin mystery-roles` — عرض الرتب والأوزان والاحتمالات التقريبية.
- `/quests-admin level-role-add` — ربط رتبة بمستوى.
- `/quests-admin level-role-remove` — إزالة مكافأة مستوى.
- `/quests-admin level-roles` — عرض جميع مكافآت المستويات.
- `/quests-admin daily-count` — عدد المهام اليومية.
- `/quests-admin weekly-count` — عدد المهام الأسبوعية.
- `/quests-admin level-xp` — XP المطلوب لكل مستوى.
- `/quests-admin daily-hour` — ساعة إعلان المهام اليومية.
- `/quests-admin message-cooldown` — مهلة احتساب الرسائل لمنع السبام.
- `/quests-admin announcement` — قناة إعلانات المهام.
- `/quests-admin log` — قناة السجلات.
- `/quests-admin ticket` — قناة تذاكر المكافآت.
- `/quests-admin event-reward` — المكافأة الافتراضية للفعاليات.
- `/quests-admin season` — اسم الموسم وبدايته ونهايته.

كل أوامر الإدارة تتطلب **Manage Server**، والرتب التي يمنحها البوت يجب أن تكون أسفل أعلى رتبة للبوت وغير Managed.

## الإعداد الأولي

بعد تشغيل البوت، لا تحتاج إلى تعديل إعدادات Quests من الملفات. استخدم `/quests-admin` داخل السيرفر.

المتغيرات المطلوبة للتشغيل فقط هي بيانات تسجيل الدخول الأساسية للبوت مثل `DISCORD_TOKEN` و`CLIENT_ID`، بالإضافة إلى إعدادات البوت الاختيارية العامة.

## التشغيل

1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. ضع Bot Token وClient ID.
5. فعّل Intents المستخدمة من Discord Developer Portal.
6. نفّذ `npm start`.
7. استخدم `/quests-admin` لإكمال إعداد السيرفر.

## قاعدة البيانات

يستخدم البوت SQLite مع WAL. يتم حفظ التقدم، الإنجازات، الصناديق، الأحداث، الـXP، الترتيبات، الإعدادات ومكافآت الرتب في قاعدة البيانات المحلية.

ملفات SQLite مستبعدة من Git عبر `.gitignore` ولا يجب رفعها إلى GitHub.
