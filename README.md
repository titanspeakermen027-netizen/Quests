# Quests

بوت Discord احترافي للحفاظ على تفاعل المجتمع عبر **Daily Quests** و**Weekly Quests** و**Seasonal Quests**، مع XP، مستويات، Quest Streak، Achievements، Mystery Boxes وفعاليات تفاعلية بالأزرار.

## الأنظمة

### 📋 Daily Quests
مهام تتجدد يومياً، ويكون التقدم مستقلاً لكل عضو. الأنواع الحالية تشمل الرسائل، التفاعلات، الوقت في القنوات الصوتية، المشاركة في الفعاليات، استخدام الأوامر والتفاعل في قنوات مختلفة.

إكمال جميع مهام اليوم يمنح العضو **Mystery Box** واحداً.

### 📅 Weekly Quests
مجموعة مهام أسبوعية بأهداف أكبر ومكافآت أعلى. التقدم يستمر طوال الأسبوع ولا يتأثر بتجدد المهام اليومية.

### 🌟 Seasonal Quests
كل موسم له فترة بداية ونهاية، وتُنشأ له مهام خاصة طويلة المدى. يمكن الإدارة إعداد الموسم من داخل Discord باستخدام `/quest-settings season`.

### ✨ XP & Levels
كل نقاط المهام تتحول إلى XP، ويمكن للإدارة تحديد مقدار XP المطلوب لكل مستوى. يمكن أيضاً ربط رتب محددة بمستويات معينة:

`/quest-settings level-role-add`

عند وصول العضو إلى المستوى، يحاول البوت منحه الرتبة المحددة تلقائياً.

### 🔥 Quest Streak
يتم احتساب السلسلة اليومية عند إكمال مهام يومية، مع حفظ أفضل سلسلة وصل إليها العضو.

### 🏅 Achievements
إنجازات تلقائية للتقدم، النقاط، الـStreak، الصناديق والمستويات وإكمال يوم كامل.

### 🎁 Mystery Box
الصندوق يُكتسب بعد إكمال جميع مهام اليوم. عند فتحه يختار البوت رتبة من الرتب المسموح بها باستخدام أوزان عشوائية.

بعد منح الرتبة، يرسل البوت للعضو رسالة في الخاص تطلب منه فتح تذكرة لاستلام المكافأة. يمكن تحديد قناة التذاكر من `/quest-settings ticket`.

### 🎉 Events
الإدارة تنشئ فعالية من `/quest-event create`، ويظهر Panel يحتوي أزرار:

- ✅ أشارك
- 👥 المشاركون
- ⏹️ إنهاء الفعالية

عند الضغط على المشاركة، يتم تسجيل العضو مرة واحدة فقط، ومنحه نقاط الفعالية، وتسجيل المشاركة أيضاً ضمن مهام الفعاليات اليومية/الأسبوعية/الموسمية.

## الأوامر

`/help` — عرض جميع الأنظمة والأوامر.

`/quests` — عرض المهام اليومية والتقدم والمكافآت.

`/quests-weekly` — عرض المهام الأسبوعية.

`/quests-season` — عرض مهام الموسم ونقاط الموسم.

`/quests-top` — ترتيب عام أو أسبوعي أو موسمي.

`/quest-profile` — عرض المستوى وXP والنقاط والـStreak والصناديق والإنجازات.

`/quest-streak` — عرض السلسلة الحالية وأفضل سلسلة.

`/achievements` — عرض الإنجازات المفتوحة والمقفلة.

`/mystery-box` — فتح صندوق حصلت عليه.

`/quest-event create` — إنشاء فعالية تفاعلية.

`/quest-event end` — إنهاء الفعالية الحالية.

`/quest-event info` — عرض معلومات الفعالية الحالية.

`/quest-settings` — إعداد نظام Quests من داخل السيرفر.

## إعدادات الإدارة

`/quest-settings view` — عرض الإعدادات الحالية.

`/quest-settings daily-count` — تحديد عدد المهام اليومية من 3 إلى 8.

`/quest-settings weekly-count` — تحديد عدد المهام الأسبوعية من 2 إلى 7.

`/quest-settings level-xp` — تحديد XP المطلوب لكل مستوى.

`/quest-settings announcement` — تحديد قناة الإعلان اليومية.

`/quest-settings log` — تحديد قناة السجلات.

`/quest-settings ticket` — تحديد قناة تذاكر مكافآت Mystery Box.

`/quest-settings season` — إعداد اسم الموسم وتاريخ البداية والنهاية.

`/quest-settings level-role-add` — ربط رتبة بمستوى.

`/quest-settings level-role-remove` — حذف رتبة مستوى.

## Mystery Box Configuration

يمكن تحديد الرتب والأوزان في `.env`:

`MYSTERY_BOX_ROLE_IDS=111111111111111111,222222222222222222,333333333333333333`

`MYSTERY_BOX_ROLE_WEIGHTS=60,30,10`

كل رقم في `MYSTERY_BOX_ROLE_WEIGHTS` يقابل نفس ترتيب الرتبة في `MYSTERY_BOX_ROLE_IDS`.

## التشغيل

1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. ضع Bot Token وClient ID والإعدادات المطلوبة.
5. فعّل Intents المستخدمة من Discord Developer Portal.
6. نفّذ `npm start`.

## قاعدة البيانات

يستخدم البوت SQLite مع WAL. يتم حفظ التقدم، الإنجازات، الصناديق، الأحداث، الـXP، الترتيبات والسجل في قاعدة البيانات المحلية.

ملفات SQLite مستبعدة من Git عبر `.gitignore` ولا يجب رفعها إلى GitHub.
