# Quests

بوت Discord احترافي لرفع تفاعل الأعضاء من خلال Daily Quests وPoints وQuest Streak وAchievements وMystery Boxes قابلة للكسب.

## الفكرة

كل يوم يحصل كل سيرفر على مجموعة مهام جديدة. العضو ينفذها بشكل طبيعي من خلال التفاعل، الرسائل، التفاعلات، القنوات الصوتية، الأوامر والفعاليات. كل مهمة مكتملة تمنح نقاطاً، وإكمال جميع مهام اليوم يمنح Mystery Box واحداً.

## المزايا

- 🔄 مهام يومية تتغير تلقائياً لكل سيرفر.
- 🎯 مجموعة كبيرة من أنواع المهام: الرسائل، التفاعلات، Voice، الأوامر، الفعاليات والقنوات المختلفة.
- 👤 تقدم مستقل تماماً لكل عضو.
- ⭐ نقاط محفوظة في SQLite.
- 🏆 `quests-top` لترتيب الأعضاء حسب النقاط ثم إجمالي المهام ثم أفضل Streak.
- 🔥 `Quest Streak` يحسب أيام النشاط المتتالية.
- 🏅 `Achievements` مع فتح تلقائي وحفظ دائم.
- 🎁 Mystery Box قابل للكسب وليس مجانياً؛ يتم منحه بعد إكمال جميع مهام اليوم.
- 🎲 Mystery Box يدعم الاختيار العشوائي الموزون للرتب.
- 📩 بعد الفوز، تصل للعضو رسالة خاصة تطلب منه فتح تذكرة لاستلام المكافأة.
- 🛡️ حماية أساسية من استغلال مهام الرسائل عبر cooldown ومنع تكرار نفس المحتوى.
- 🎙️ تتبع وقت Voice مع حفظ دوري، ويعاد بناء الجلسات عند تشغيل البوت.
- 📊 `quest-profile` لعرض النقاط، المهام، Streak، الصناديق والإنجازات.
- 📝 قناة Logs اختيارية لمكافآت الصناديق والإنجازات.
- 🇸🇦 جميع رسائل البوت بالعربية الفصحى، مع بقاء أسماء الأوامر بصيغة Discord القياسية.

## الأوامر

`/quests` — عرض مهام اليوم والتقدم والمكافآت.

`/quests-top` — عرض أفضل 10 أعضاء في نظام المهام.

`/quest-profile` — عرض إحصائيات العضو الكاملة.

`/quest-streak` — عرض السلسلة الحالية وأعلى سلسلة.

`/achievements` — عرض الإنجازات المفتوحة والمقفلة.

`/mystery-box` — فتح صندوق مكتسب والحصول على رتبة عشوائية.

`/quest-event user:@member` — تسجيل مشاركة عضو في فعالية، للمشرفين الذين يملكون Manage Server.

## Mystery Box

الصندوق لا يُفتح بمجرد كتابة الأمر. يجب أن يكون لدى العضو صندوق متاح في رصيده.

عند إكمال جميع مهام اليوم مرة واحدة يحصل العضو على Mystery Box واحد لذلك اليوم. يمكن معرفة عدد الصناديق من `/quest-profile`.

### الرتب

ضع معرفات الرتب داخل:

`MYSTERY_BOX_ROLE_IDS=111111111111111111,222222222222222222,333333333333333333`

ويمكنك تحديد احتمالات مختلفة عبر:

`MYSTERY_BOX_ROLE_WEIGHTS=60,25,15`

القيم الموزونة مرتبطة بالترتيب نفسه. إذا كانت القيم غير صالحة يستخدم البوت احتمالاً متساوياً.

البوت يستبعد تلقائياً الرتب التي لا يستطيع إدارتها والرتب التي يملكها العضو بالفعل.

## رسائل الـDM والتذاكر

بعد فتح Mystery Box ومنح الرتبة، يرسل البوت للعضو رسالة خاصة مثل:

> 🎁 تم فتح Mystery Box بنجاح!
>
> 🎉 حصلت على الرتبة: **اسم الرتبة**
>
> 📩 يرجى فتح تذكرة داخل السيرفر لاستلام المكافأة.

لتحديد قناة التذاكر التي تظهر في الرسالة، ضع `TICKET_CHANNEL_ID`.

البوت لا ينشئ نظام Tickets من تلقاء نفسه؛ إنشاء التذكرة الفعلية يبقى مرتبطاً بنظام التذاكر الموجود في السيرفر.

## إعداد البيئة

1. استخدم Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. ضع `DISCORD_TOKEN` و`CLIENT_ID`.
5. حدّد `MYSTERY_BOX_ROLE_IDS`.
6. شغّل البوت عبر `npm start`.

أثناء الاختبار يمكنك وضع `GUILD_ID` لتسجيل الأوامر مباشرة في سيرفر واحد. اتركه فارغاً عند الاعتماد على التسجيل العام.

## Anti-Spam

افتراضياً لا يتم احتساب كل رسالة بشكل أعمى. يجب أن تكون الرسالة ذات محتوى قابل للاحتساب، ولا يتم احتساب نفس المحتوى المتكرر، كما يوجد cooldown افتراضي 8 ثوانٍ بين نقاط مهام الرسائل لكل عضو.

يمكن تعديل ذلك من:

`MESSAGE_PROGRESS_COOLDOWN_SECONDS`

## تخزين البيانات

يستخدم البوت SQLite مع WAL. ملف قاعدة البيانات الافتراضي هو `quests.sqlite`، وهو مدرج ضمن `.gitignore` ولا يجب رفعه إلى GitHub.

قاعدة البيانات تحتوي على تقدم العضو، المهام اليومية، الإنجازات، رصيد الصناديق، جلسات Voice وإعدادات إضافية.
