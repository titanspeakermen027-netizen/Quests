# Quests

بوت Discord احترافي للحفاظ على تفاعل الأعضاء عبر مهام يومية، نقاط، سلاسل إنجاز، Achievements وMystery Boxes.

## المزايا الحالية

- مهام يومية تتجدد حسب تاريخ السيرفر.
- أنواع مهام: الرسائل، التفاعلات، الوقت في القنوات الصوتية، المشاركة في الفعاليات، واستخدام أوامر البوت.
- تقدم مستقل لكل عضو.
- نظام نقاط مرتبط بالمهام.
- `Quest Leaderboard` لترتيب الأعضاء حسب النقاط ثم الإنجازات.
- `Quest Streak` للسلسلة الحالية وأعلى سلسلة.
- `Achievements` قابلة للفتح تلقائياً.
- `Mystery Box` مع اختيار عشوائي من رتب محددة.
- إرسال نتيجة الـMystery Box إلى الخاص مع طلب فتح تذكرة.
- SQLite مع WAL للحفاظ على البيانات محلياً.
- جميع رسائل البوت بالعربية الفصحى.

## الأوامر

`/quests` — عرض مهام اليوم والتقدم والمكافآت.

`/quests-top` — عرض ترتيب الأعضاء.

`/quest-streak` — عرض السلسلة الحالية وأفضل سلسلة.

`/achievements` — عرض الإنجازات المفتوحة والمقفلة.

`/mystery-box` — فتح الصندوق الغامض وفق فترة التبريد المحددة.

`/event-complete user:@member` — تسجيل مشاركة عضو في فعالية (للمشرفين).

## التشغيل

1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. ضع Bot Token وClient ID وباقي الإعدادات.
5. نفّذ `npm start`.

## إعداد Mystery Box

ضع معرفات الرتب داخل `MYSTERY_BOX_ROLE_IDS` مفصولة بفاصلة، مثال:

`MYSTERY_BOX_ROLE_IDS=111111111111111111,222222222222222222,333333333333333333`

يختار البوت رتبة واحدة عشوائياً من القائمة عند فتح الصندوق، ثم يمنحها للعضو إذا كان ترتيب رتبة البوت يسمح بذلك.

## إعداد التذاكر

ضع `TICKET_CHANNEL_ID` ليظهر اسم قناة التذاكر في رسالة الخاص بعد الفوز بمكافأة Mystery Box. إنشاء التذكرة نفسها يظل مرتبطاً بنظام التذاكر الذي تستخدمه في السيرفر.

## مهمات المشاركة في الفعاليات

إدارة السيرفر تسجل المشاركة عبر `/event-complete user:@member`. هذا يجعل الفعاليات قابلة للربط مع أي نظام فعاليات خارجي لاحقاً دون تغيير قاعدة البيانات.

## ملاحظات تشغيلية

فعّل `Message Content Intent` و`Server Members Intent` و`Guild Message Reactions Intent` و`Guild Voice States` من Discord Developer Portal حسب الأنظمة المستخدمة في السيرفر.

البيانات المحلية موجودة في `quests.sqlite` ولا يجب رفعها إلى GitHub.
